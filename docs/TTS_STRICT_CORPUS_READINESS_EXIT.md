PR #83 — Strict readiness exit for unattended phonetic corpus QA. The normal read-only audit returns 0 when it correctly generates a report, but --require-ready now returns 2 if the technical phonetic benchmark is NOT independently validated, while still writing the evidence report. Automation can therefore distinguish successful auditing from successful pronunciation validation without human intervention. Strict does not weaken evidence criteria, publish teaching assets or invent human review results.
