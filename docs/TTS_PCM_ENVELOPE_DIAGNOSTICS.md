PR #58 — WAV envelope/PCM measurements without model calls. The module streams mono PCM16 (10/20/40 ms short-time RMS, zero-signal and clipping fractions), validates duration bounds and WAV frame count, hashes input before and after. It cannot determine yay/why or identify a mispronunciation. Real test inputs: lecturer-confirmed faulty and corrected Thomas 2.5 slide-10 WAVs. No NumPy/SciPy/Whisper dependency, no writes to original audio, no human gates.
