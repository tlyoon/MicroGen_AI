## What the new algorithm does
`microgen_corrected_exception_screen.py` independently reads only a **SHA-pinned and internally verified original textbook review packet**. It validates the entire 130-file reviewer packet and its source receipt, matches each of the 17 corrected reference WAVs to its prior SHA-256, measures per-slide actual mono PCM16 sample rate, RMS loudness, near-clipping and quiet-sample fraction, and compares source narration words against the independently captured Vosk hypothesis. These are *screening signals only*. A short title slide is exempt from long-narration word-sequence screening.

Every identified source-PDF mathematical/figure region is retained, sorted into `REVIEW_FIRST` or `PENDING_REVIEW` without assigning academic approval; a conservative math-region script+ASR lexical overlap may reduce inspection priority but is never called equation correctness. Known historical `c` and `y-value` replacement trials (slides 5/6/10) stay high priority. An offline `index.html` points to independently SHA-checked source crops and corrected audio, `exception_priority.csv` holds all `UNREVIEWED` decisions, and `exception_screen_receipt.json` records all flags and source evidence. The code has NO paid API, Whisper, network request, voice-ID service, GitHub publication or source overwrite operations.
