# PR238 — Transactional one-call offline Serway 1.1 lecture campaign

This is the next step after source-bound PR237 real MP4. It eliminates the need to manually run the earlier independent stage scripts and connect their intermediate artifact directories. The user supplies only the trusted private original Serway 1.1 source folder, PR235 fourteen-slide narration and visual plan, and locally installed Piper/Vosk/FFmpeg paths. The code creates all **new** output folders and SHA receipts itself.

One call performs: (1) original source PDF + Figure1.1 SHA verification and immutable model/voice metadata checks, (2) freshly render 14-slide source-grounded teaching PDF, (3) independent strict section-1.1 academic concept/cross-reference audit, excluding the start of §1.2, (4) synthesize all fourteen corrected Piper neural PCM16 WAV candidates in a new folder, (5) each WAV signal/duration/clipping/SHA QA, (6) offline Vosk pronunciation advisory with source-locked WAV SHA, (7) actual H264/AAC MP4 mux with every slide midpoint frame/pixel and A/V drift verification, and (8) immutable-source revalidation and atomic commit of a final receipt.

**Transaction safety:** all intermediates are created under one fresh private temporary directory outside the source tree and Google Drive. Any Python/FFmpeg/TTS/ASR, provenance, license-card, source-integrity or source-semantic failure cleans up the candidate directory and does not create the advertised final folder. A fully completed result remains a *not-for-publication candidate*; no manual academic approval step is silently invented, but complete unverified scientific claims and full phonetic/rights approvals are not implied.

The pipeline accepts no paid TTS provider options and performs no external API calls. Only the locally installed Piper voice model and optional Vosk recognition are used, with no historical default voice change. Piper trained-from-scratch/public-domain dataset statements in its card do not independently license distribution of model weights or copyrighted figure content.

The PR includes five synthetic tests for unique fresh output, immutable inputs, stage receipt and source hash links, successful transactional publication-blocked completion with stubbed external speech/video stages, failure rollback, and false model licensing metadata. The end-to-end real HP campaign also runs directly using the installed source and local engines to produce a second **independent** 14-slide MP4 candidate in `%LOCALAPPDATA%\MicroGen_AI_Checkpoints\20261101_HP_PR238_SINGLE_CALL_FULL_SOURCE_TO_VIDEO`.

This pipeline is explicitly a complete **Serway 1.1** pilot and must not be sold as arbitrary chapter support. The next priority should generalize academic and figure coverage contracts beyond this single pinned textbook subsection and run a second independent original-source pilot.
