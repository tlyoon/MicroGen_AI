# PR #38 — SHA-bound all-slide human listening queue

This PR produces a **non-authoritative review queue**, not a signed human approval. Every slide is included, even when automatic acoustic transcription passes, since recognition can silently normalize a defective spoken mathematical letter. Confirmed risk classes (math Y letter / C circa) take highest review priority; other scientific expressions follow. Every row binds an exact WAV SHA and source narration SHA, measured slide boundaries and optional checked short listening clips. The clip cues are approximate, not forced alignment, so whole-slide listening is necessary.

Use `python microgen_tts_listening_queue.py ISOLATED_STAGE NEW_QUEUE.json [--clip-manifest CLIPS.json --clip-folder CLIPS_DIR]`. Existing queue files cannot be overwritten. A lesson contains all 17 slide review items even if only some have pronunciation-risk flags. **No automatic approval is ever written.** An independent reviewer process must listen, record all slide decisions and sign them using the separate per-role trusted signing keys from PR #36; the QA generator does not own those keys. No source audio/MP4, original WAV or user credential is modified.
