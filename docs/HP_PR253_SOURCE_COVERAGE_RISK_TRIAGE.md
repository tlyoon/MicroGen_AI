# PR253 — nonblocking source-context coverage and semantic-risk triage

The PR247 original-authoring gate currently verifies each topic has an exact source anchor, at least one source/visible/spoken technical term, no 12-token exact source copying, and no invented numerical literals. Those are strong *structural checks* but cannot independently prove that a generated lecture preserves a textbook's complete concepts or that every narrative claim follows from the textbook.

This milestone adds microgen_portable_semantic_coverage_triage.py, a deterministic and zero-provider, nonblocking, local-only audit of ChatGPT/Gemini-authored teaching topics versus original bounded PDF evidence blocks. PR247's existing strict SHA/page/bbox/source-bound authoring validation continues to run before the report is accepted, then the audit is packaged under source_coverage_semantic_risk_triage inside the fresh private authoring_private_qa.json.

It records per-topic source passage IDs and page, source evidence categories, a short sorted sample of novel long words in independently paraphrased lectures, and per-passage cited-by count. It highlights unreferenced passages containing likely worked examples, quick quizzes, original figure captions/mentions and measurable unit/quantity contexts. All source and authored words remain in the PRIVATE HP stage; the report contains only ID/page/category/short lexical observations, not full copyrighted source passages.

**Explicit epistemic guardrails:** A cited source block is not proof of physical entailment, an unreferenced block is not proof that an important concept is missing, a long new word is not a hallucination, and a category inferred by a simple regex is not a verified learning objective. Findings NEVER block a structurally valid lecture and NEVER assert academic completeness, figure identity, copyright permission or publication approval. This avoids recurring overly stringent QA gates and busywork while making the unresolved content evidence visible for a later model-guided review. No automatic GPT or Gemini API calls, no local language models, no new paid services or devices.
