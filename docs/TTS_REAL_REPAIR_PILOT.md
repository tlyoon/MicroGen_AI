# PR #35 — Real Thomas Calculus 2.5 bounded repair pilot

Run only on Dell-115, using a locally isolated QA stage containing the prior reviewed corrected Slide 10 WAV and its historical defective backup. The module `microgen_tts_real_pilot.py` creates a completely new scratch copy, verifies the historical defective WAV SHA, verifies the previously listener-approved corrected WAV reference hash, and injects the old defective WAV *only into scratch*. It then rebuilds the source risk ledger, checks it covers the approved Y-value correction, calls PR #31's bounded repair engine with an injected production provider, and assembles a **new review-video input directory** with the newly synthesized candidate WAV and unchanged other slide WAVs.

The pilot never modifies, deletes, commits or uploads original WAV/MP4/PDF/script; user approvals on the previous corrected audio **do not automatically transfer** to a newly synthesized candidate with a different audio hash. When live independent recognition is unavailable, it records acoustic QA as UNKNOWN, and *no* academic, audio listening, figure or element highlight approval is fabricated. A separate renderer may generate a review MP4 from the scratch directory; the strict PR #32 release audit must then reject missing review receipts. Every part remains unpublished pending independent listening and release authorization.

Acceptance: stage source hashes retained, no provider fallback substitution, no stage overwrite, candidate WAV checksum and time preserved, below-600s review target or multipart request, and missing voice/acoustic/academic/figure/highlight review blocks release.
