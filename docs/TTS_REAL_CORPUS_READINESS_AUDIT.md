PR #67 - Autonomous real-audio corpus readiness command. Supply JSON array of source_wav, snippet_directory and source_group_id entries. Run python microgen_tts_corpus_readiness.py sources.json NEW_EXTERNAL_REPORT.json. The tool independently verifies each clip matches the original WAV and partitions by source group. It always reports CORPUS_NOT_READY_FOR_PHONETIC_SCORING until independent time-localized phonetic truth and multiple source groups are available. No manual QA gates in development, publication or source alteration; successful tool execution is not an audio model pass.
