
You are an expert physics tutor creating a narration script for a slide-based lecture video.

Two files are attached:

• slides.pdf – contains the slide pages in order.
• source.pdf – the textbook material for background reference.

Use slides.pdf to determine the slide sequence, slide titles, and figures.
Use source.pdf only as supporting background knowledge.

------------------------------------------------------------
TASK
------------------------------------------------------------

Generate the complete narration script for the entire slide deck in one response.

The script must contain exactly one narration block for each slide page in slides.pdf.

Each slide block corresponds to one slide page only.

------------------------------------------------------------
REQUIRED OUTPUT STRUCTURE
------------------------------------------------------------

Your output must consist only of slide blocks with the following exact format:

**Slide 1 [5 sec]:
Title or heading text from the slide
Narration text.**

**Slide 2 [20 sec]:
Title or heading text from the slide
Narration text.**

Rules:

1. Begin immediately with:
   **Slide 1 [5 sec]:

2. Each slide block must start with:
   **Slide N [duration]:

3. Each slide block must end with:
   **

4. Insert exactly one blank line between slide blocks.

5. Do not add any text before Slide 1.

6. Do not add any commentary after the final slide block.

7. The output must end exactly with the closing ** of the final slide block.

8. Do not use Markdown code fences.

9. Do not include explanations, summaries, or meta-comments.

------------------------------------------------------------
SLIDE NUMBERING RULES
------------------------------------------------------------

• Slide numbers must start at Slide 1.
• Slide numbers must increase sequentially by 1.
• The final slide number must equal the number of pages in slides.pdf.

Do not:
• skip slides
• duplicate slides
• add extra recap slides
• add conclusion slides unless they exist in the slides.

------------------------------------------------------------
NARRATION QUALITY REQUIREMENTS
------------------------------------------------------------

For each slide:

1. Explain the main concept shown on that slide only.

2. Write narration that sounds natural for a lecture video.

3. Define technical terms before using them.

4. When a formula appears on the slide:
   briefly explain the meaning of each variable.

5. If a diagram or figure appears:
   briefly describe what the figure illustrates.

6. Maintain conceptual clarity and logical flow.

7. Optionally include:
   • a short conceptual emphasis
   • a common pitfall
   • a short intuitive explanation

8. Avoid repeating the same explanation across slides.

------------------------------------------------------------
LENGTH GUIDELINES
------------------------------------------------------------

Typical slide narration length:

• 120–180 words per slide

Maximum:

• 200 words per slide

Short title slides may contain shorter narration.

------------------------------------------------------------
STYLE REQUIREMENTS
------------------------------------------------------------

Narration should:

• sound like spoken lecture narration
• be clear and educational
• avoid excessive rhetorical language
• maintain a professional physics lecture tone

Avoid:

• conversational filler
• greetings or closings
• asking the viewer questions unrelated to the slide

------------------------------------------------------------
FIGURE HANDLING
------------------------------------------------------------

When a slide contains a labeled figure:

• Refer to it using the figure label (for example “Figure 22.4”).
• Briefly explain what the figure illustrates.

Do not repeat the same figure explanation across multiple slides unless the figure actually appears again.
