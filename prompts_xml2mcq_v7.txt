     <answer fraction="...">

- If the source stem presents exactly K labeled options (e.g., A–D), use that K.
- Otherwise, default K = 5.
- Fractions: exactly one fraction="100" and the remaining (K−1) fraction="0".

- Keep units consistent and magnitudes reasonable.
- No meta commentary in the output.

# 🧼 SOURCE TEXT HYGIENE
- Keep only the problem statement needed to answer.

# 🔁 IF INPUT IS NOT A SINGLE QUESTION
